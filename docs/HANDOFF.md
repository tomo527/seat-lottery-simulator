The authorized `VENUE-SOURCE TRANSPORT POLICY IMPLEMENTATION` is complete. It is a policy-only change: **no venue data, fingerprint, or generated artifact was touched**, and production was unchanged by it at the **132 venues / 134 selectable configurations / 181,441 configuration-seat records** current in that wave.

The new contract replaces the former unconditional `sources[].url` HTTPS requirement. A recorded URL is provenance and audit metadata only — the repository audit confirmed that no build step and no runtime path dereferences it, that the generated catalog and the 134 runtime payloads contain no URL at all, and that no runtime type carries a `sources` field — so transport is now judged as evidence-record quality rather than as a user-facing link control. HTTPS stays mandatory wherever the issuer serves it. A current first-party official issuer that serves no working HTTPS endpoint may now be recorded at its real `http://` URL under an explicit, machine-checkable `httpOnlyOfficial` waiver holding `issuerDomain` (must match the URL host or a host below it), `httpsCheckedAt` (valid, non-future), and `httpsUnavailableEvidence`. Waiverless HTTP, non-official HTTP, incomplete waivers, issuer-domain mismatch, malformed URLs, and a waiver left on an HTTPS URL are all still errors; an accepted HTTP source raises a standing warning, and the waiver expires into a recheck warning after `WARNING_LIMITS.httpsRecheckDays` (180). Rewriting an HTTP issuer URL to an invented HTTPS address stays prohibited, and the waiver relaxes no seat-evidence, currentness, issuer-ownership, or configuration requirement.

The policy has one implementation, [`scripts/venues/source-transport.mjs`](../scripts/venues/source-transport.mjs), shared by all three gates that previously enforced HTTPS separately: the source validator (`scripts/venues/validation.mjs`), the inventory `officialFacilityUrl` gate (`scripts/venues/inventory.mjs`, which applies the same waiver shape to inventory records), and the production database test (`src/data/venue-db/venueDatabase.test.ts`, which now evaluates the shared predicate instead of asserting an `https://` prefix). Changing the contract means changing that one module.
